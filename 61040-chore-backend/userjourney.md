# User Journey

## Character Profile + Story
Baxter (M22) is undergraduate student at MIT. Lives in Cambridge with 2 roommates. Enjoys going out with friends but hates wasting time waiting in lines. Uses apps regularly but values privacy.

- Baxter and friends spend 20 minutes in group chat trying to decide where to go, with no reliable information about wait times or crowd levels
- Baxter downloads WaitLess app, which has an anonymous mode option for privacy
- Baxter uses map view to see real-time venue data: red/yellow/green indicators for crowd levels, recent user reports, and wait times
- Baxter discovers a cocktail bar with live jazz starting soon and no current wait - information impossible to find elsewhere
- Baxter shares venue with friends, shows them the vibe rating (4.2/5 from 47 reports) and recent user reports to convince them
- Baxter sets notification alert for if wait time exceeds 20 minutes
- Baxter arrives to find venue exactly as described - moderate crowd, no wait, jazz setting up
- Baxter submits his own report (0 min wait, moderate crowd, live jazz) contributing to the community
- Baxter later checks app when another friend wants to join - sees venue is now getting crowded with 15 min wait
- Baxter uses predictive feature to advise friend about peak times (10 PM) and when it will quiet down
- Baxter filters for "high energy" venues when group wants to move somewhere more energetic
- Baxter finds a club with DJ set starting and knows exactly what to expect

## The Transformation

### Before WaitLess
- Baxter spends 20+ minutes in group chat trying to decide where to go, with no reliable information about wait times or crowd levels
- Baxter risks going to multiple venues
- Baxter has no real-time information
- Baxter has potential for wasted time and money

### After WaitLess
- Baxter makes informed decisions
- Baxter has confidence in venue choice
- Baxter has real-time updates during the evening
- Baxter can help others through contributions
- Baxter has privacy-respecting experience
